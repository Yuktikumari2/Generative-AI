# Gemini Pro Applicant Tracking System (ATS) 🎯
Welcome to the Gemini Pro Applicant Tracking System (ATS)! This system leverages the Gemini Pro model to streamline resume screening, enhancing the efficiency of the hiring process. It provides insightful metrics such as Job Description Match, Missing Keywords, and a Profile Summary, empowering recruiters to identify top candidates quickly and accurately.

## Features
### Job Description Match: 
Calculates the alignment percentage between the resume and job description, making it easy to spot ideal candidates.
### Missing Keywords: 
Highlights essential skills or keywords that may be absent, guiding applicants toward profile enhancement.
### Profile Summary: 
Generates a concise summary of key strengths and qualifications for a clear view of the candidate’s fit for the role.

## Requirements
Python Version: 3.8+

Gemini Pro API Key: Obtain a valid API key (see installation instructions).

## Installation
### 1. Clone the Repository
Clone the project repository using the following command:

git clone https://github.com/Yuktikumari2/Generative-AI/

### 2. Install Dependencies

Navigate to the project directory and install required libraries:

pip install -r requirements.txt

### 3. Set Up Gemini Pro API Credentials
Obtain your API key from Google Makersuite.

Create a .env file in the project’s root directory.

Add your API key in .env as follows:

GOOGLE_API_KEY=your_api_key

## Usage
Run the Application

streamlit run app.py

Access the ATS in Your Browser Open http://localhost:5000 to interact with the application.

## Input Details

Paste the job description and upload the resume in the designated fields.

Analyze and Review Results

Click "Submit" to start the analysis.

View results for job description match, missing keywords, and a tailored profile summary.
